# Instruções de Download do Dataset (database_tiny)

Para executar o código de confiabilidade com a base de dados reduzida (*tiny*), siga os passos abaixo:

1. **Baixar os dados**:
   Acesse o link abaixo e faça o download da pasta compactada contendo a pasta **Vibration**:
   [Link para Download (OneDrive)](https://1drv.ms/f/c/5f1c3aa3f12af1a2/IgCQGLn6yKEJSYROXE3234L7ATsM_BTAQAUlq3rVgTFJBkk?e=TdzSMO)

2. **Extração**:
   Extraia o conteúdo baixado diretamente na raiz desta pasta (`database_tiny`).

3. **Estrutura final**:
   Certifique-se de que a pasta de vibração fique no seguinte caminho físico:
   `\confiabilidade\data\database_tiny\Vibration`

   Dentro de `Vibration`, deve haver as subpastas `Motor-2` e `Motor-4`, conforme a estrutura original do dataset.
